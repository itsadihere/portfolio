# Aditya Pratap Singh Bhadoriya — Portfolio

AI Data Analyst · BI Developer · AI Automation Engineer

A single-file, dependency-free portfolio website (pure HTML/CSS/JS) with a warm
deep-space theme, particle background, animated skill panels, an auto-scrolling
certificate carousel, and a 3D-tilt project showcase.

**Live:** https://itsadihere.github.io/portfolio/

## Structure
- `index.html` — the entire site (HTML + CSS + JS in one file)
- `images/` — profile photo (`profile.png`) and certificate images (`cert-1.png` … `cert-6.png`)

## Editing
- Add a certificate: drop `cert-N.png` in `images/`, then add one line to the
  `ALL_CERTS` array in `index.html`.
- Add a flagship credential: add a line to the `FLAGSHIP_CERTS` array.
